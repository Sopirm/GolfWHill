# Настройка вспомогательной механики

## Что уже реализовано в коде
- Система достижений с сохранением в `PlayerPrefs`
- Ежедневные награды с серией входов
- Метапрогресс игрока: уровень, XP, валюта
- Игровые события для энергии, способностей, комбо, времени и движения машины
- UI-скрипты для достижений, наград, попапов и панели прогресса

## Что нужно создать вручную
1. `AchievementSystem`:
   - `Assets -> Create -> Game -> Achievement System`
2. `DailyRewardSystem`:
   - `Assets -> Create -> Game -> Daily Reward System`
3. На сцене пустой объект `AuxiliarySystems`
4. На `AuxiliarySystems` добавить:
   - `PlayerMetaProgress`
   - `AuxiliarySystemsBootstrap`
   - `DailyRewardManager`
5. На машину добавить:
   - `VehicleProgressTracker`

## Что нужно связать в Inspector
- В `AuxiliarySystemsBootstrap`:
  - `Achievement System`
  - `Daily Reward System`
- В `DailyRewardManager`:
  - `Daily Reward System`
  - `Player Meta Progress`
  - `Energy System`
  - `Feedback System`

## Что нужно сделать в Canvas
- Панель метапрогресса:
  - текст уровня
  - текст XP
  - текст монет
  - полоска XP
- Панель достижений:
  - контейнер списка
  - префаб одного достижения
  - тексты статистики
  - фильтры
  - сортировка
- Панель ежедневных наград:
  - контейнер списка
  - префаб одного дня
  - текст серии
  - текст таймера
  - текст бонуса
- Попап достижения:
  - иконка
  - заголовок
  - описание

## Что проверять
1. Сбор энергии обновляет достижения
2. Поездка на машине обновляет дистанцию и скорость
3. Использование способностей обновляет достижения по способностям и комбо
4. Получение ежедневной награды даёт XP, монеты или энергию
5. Прогресс сохраняется между запусками
