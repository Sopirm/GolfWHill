1. Основная формула механики:
Стоимость способности рассчитывается по формуле
cost(level) = round(baseCost * growth^(level - 1)).
Для комбо используется формула
comboBonus = baseBonus * (1 + chainLength * 0.3).

2. Параметры баланса сложности:
- базовое количество энергии за сбор
- максимальная ёмкость каждого типа энергии
- рост стоимости способностей
- время перезарядки
- минимальная перезарядка
- деградация энергии
- окно времени для комбо

3. Точка разочарования:
Если игрок тратит более 8-10 секунд на накопление одной базовой способности и при этом теряет энергию из-за деградации, игра начинает ощущаться слишком медленной.

4. Частота наград:
Игрок получает малые награды при каждом сборе энергии, средние при активации базовых способностей и крупные при успешной комбо-цепочке. В среднем полезное событие должно происходить каждые 2-4 секунды.

5. Если увеличить стоимость всех способностей на 50%:
Увеличится время накопления, снизится темп игры, комбо станут реже, а деградация энергии начнёт сильнее наказывать игрока. Это потребует либо повысить скорость сбора, либо уменьшить деградацию.

6. Масштабирование с уровнем игрока:
С ростом уровня увеличивается допустимая ёмкость энергии, а способности становятся эффективнее за счёт роста силы и снижения времени восстановления.

7. Данные для дальнейшей балансировки:
- среднее время накопления до первой способности
- частота использования каждого типа энергии
- средняя длина комбо-цепочки
- доля потерянной энергии из-за деградации
- популярность способностей
- время между наградами
- момент выхода игрока из сессии
