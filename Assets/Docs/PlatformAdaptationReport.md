# Отчёт по адаптации проекта под разные платформы

### 1. Платформенный ввод
- Добавлен `PlatformInputManager`
- Для Android реализован runtime мобильный UI
- Для PC и WebGL сохранена клавиатурная схема управления
- Мобильный ввод интегрирован в:
  - управление машиной
  - переключение камеры
  - взаимодействие
  - открытие двери

### 2. Адаптивный интерфейс
- Добавлен `AdaptiveUI`
- Поддерживаются разные размеры шрифта и кнопок
- Можно скрывать и показывать платформо-зависимые UI-блоки
- Поддерживается адаптация под touch-интерфейс

### 3. Платформенные runtime-настройки
- Добавлен `PlatformRuntimeSettings`
- Задаются целевые FPS и качество для PC, Android и WebGL

### 4. Инструменты сборки
- Добавлено editor-меню для сборки:
  - Windows 64-bit
  - Android APK
  - WebGL
